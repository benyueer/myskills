## 1. 三个关键文件理解检查

### 1.1 招标公告理解
- [ ] 已获取招标公告
- [ ] 已理解项目基本信息（项目名称、招标编号、项目单位）
- [ ] 已了解投标人资格要求

### 1.2 招标文件理解
- [ ] 已获取招标文件
- [ ] 已理解评标办法和评分标准
- [ ] 已理解投标文件格式要求（第六章）
- [ ] 已了解合同条款
- [ ] 已了解否决情形
- [ ] 评分标准、投标格式、否决条款、签章要求均来自招标文件原文

### 1.3 技术规范书理解
- [ ] 已获取技术规范书
- [ ] 已理解功能需求
- [ ] 已理解非功能性需求
- [ ] 已理解系统架构要求
- [ ] 已理解集成需求
- [ ] 已理解部署要求
- [ ] 功能、非功能、架构、集成、部署、工作量和交付物信息均来自技术规范书

### 1.4 开始写作前置条件
- [ ] 已同时理解招标公告、招标文件、技术规范书三个关键文件
- [ ] 三个关键文件缺失任意一个时，已明确说明缺口和影响
- [ ] 未在理解三个关键文件前直接撰写正式正文
- [ ] 用户或公司补充材料仅用于团队、业绩、证书、产品和证明材料，不替代招标信息来源

## 2. 评审标准对齐检查

### 2.1 评审标准分析

### 2.2 第六章“对项目的理解”服务方案评估

- [ ] 第六章“对项目的理解”覆盖“服务方案”评审要素中所有维度；维度名称以本标的招标文件原文为准

- [ ] 如未达到“优”，已继续优化并重新自评；未把良好、一般、合格或无法判断的方案视为可接受
